# 0008b - Evidence-based Go model routing

Establish an owner-accepted routing policy for the tested Symmetry Go task
classes using the accepted 0008a workflow. Frozen representative tasks cover
both established-pattern edits and applicable resource ownership, cancellation,
native platform, persistence, or recovery-sensitive changes.

Completion requires mixed-model and strong-only runs with identical contracts,
permissions, budgets, checks, and review. Task-level evidence records actual
model identities, provenance, total known cost per accepted change, verification
and review effort, repairs, failures, and limitations; every accepted result
passes applicable Go gates and independent semantic review.

The accepted policy may recommend lightweight execution, require strong-only
execution, or record insufficient evidence for each tested class. It makes no
claim for untested Go work, Elixir, or TypeScript, depends on 0008a, is one
independently mergeable PR, and must fit one agent run of at most 12 hours.
