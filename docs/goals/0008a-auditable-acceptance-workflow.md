# 0008a - Auditable model-independent acceptance workflow

Establish a runnable workflow that executes a frozen Symmetry task contract in
an isolated checkout and binds implementation, verification, and independent
review to one exact Subject. Its receipt records the base and head revisions,
task and prompt identities, required checks, evidence, findings, repairs, costs
when known, and unresolved limitations.

Completion evidence includes positive and negative runs on real current Go or
Elixir work, rejection of stale or incomplete receipts, one bounded task that a
lightweight worker completes successfully, and one task that escalates because
its invariant or evidence exceeds that worker's supported scope.

This goal selects no model or routing policy, stores no sensitive transcript,
invents no missing cost, and never weakens tests, types, authority, recovery,
permissions, or acceptance. It is one independently mergeable PR and must fit
one agent run of at most 12 hours.
