## Full-series acceptance contract

Make Symmetry sustain engineering goals across sessions, interrupted executions
and compatible harness handoffs while preserving approved intent, authority,
useful context, dependencies and verifiable progress. Implement within the fixed
contracts in [core](../design/core.md), [data](../design/data.md),
[protocol](../design/protocol.md) and [harness](../design/harness.md).

Completion is demonstrated by real repository work using Codex, Claude Code, pi
and OpenCode within their explicitly tested capability ranges, with Linux and
Windows evidence for claimed native support. Work can recover after interruption,
continue in a retained compatible session or hand off through preserved artifacts
and versioned context, reject stale authority, stop for a consequential decision,
resume after its scoped resolution, and separate execution success from accepted
work and achieved goals. Unsupported native operations are visible as unsupported.

Executable evidence distinguishes duplicate/replayed delivery, lost acknowledgements,
stale generations, invalid dependencies, outdated context, mismatched validation,
unknown external effects and budget exhaustion from valid progression. Recovery
does not reaccept results or repeat already confirmed effects; failed work's
actual usage remains accounted. A goal's completion is traceable to the exact
artifacts, required checks and authorized acceptance, with an inspectable reason
for every blocked or continuing state.

Existing goal-less workflows, provider ownership, authentication and protocol v1
remain compatible through the documented migration. PostgreSQL remains the only
durable control authority; LoopX contributes applicable concepts without a second
writable scheduler. Native session formats are not promised portable across
harnesses. Native macOS, general workflow DSLs, multi-tenant RBAC and autonomous
unapproved scope expansion are excluded. Missing live environments or acceptance
evidence remain explicitly incomplete rather than being replaced by fake-agent
success. Documentation-only design does not complete this goal.
