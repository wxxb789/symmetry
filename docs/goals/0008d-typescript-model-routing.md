# 0008d - Evidence-based TypeScript model routing

Establish an owner-accepted routing policy for the tested Symmetry TypeScript
task classes after at least one of 0007b-0007h has merged with current,
executable frontend acceptance commands for every task class evaluated here.
Frozen tasks cover established component work and applicable decoder,
asynchronous-state, cancellation, conflict-recovery, and receipt-truth behavior.

Completion requires mixed-model and strong-only runs with identical contracts,
permissions, budgets, and evidence; strict type, lint, test, and build results;
rendered interaction and accessibility evidence where applicable; independent
contract review; and owner visual judgment for qualitative UI acceptance.

The accepted policy may recommend lightweight execution, require strong-only
execution, or record insufficient evidence. It makes no claim for Go, Elixir,
untested frontend classes, or behavior absent from the merged 0007 increments.
It depends on 0008a and the specific 0007b-0007h goals that supply its frozen
task classes; unsupported classes are removed from scope. It is one independently
mergeable PR and must fit one agent run of at most 12 hours.
