# 0006h - Credentialed provider reconciliation and accounting

Demonstrate that approved provider effects on non-production resources retain
credential locality, stable action and resource identity, unknown-outcome
readback, exact replay, and truthful provider-owned usage or accounting without
redispatching a confirmed effect.

Completion evidence comes from credentialed GitHub or Azure DevOps operations
bound to the exact Subject, including success, definitive failure, timeout with
readback, restart recovery, redaction, and billed or explicitly unavailable
usage. Dummy keys, loopback gateways, model narration, and local journal tests do
not satisfy this goal.

This goal starts only when an approved non-production resource, credentials,
provider identity, network access, and permitted spend are available; the
12-hour bound starts after those prerequisites are ready. It is one independently
mergeable PR and does not broaden provider permissions or production scope.
