# 0006i - Exact-subject release and authorized acceptance

Produce the final Goal 0006 release candidate as one exact, reviewable Subject
and complete every configured acceptance predicate against that same revision.
Hosted Linux and Windows results, native capability evidence, provider identity,
usage or accounting, and the authorized Goal decision all refer to the same
repository resource, commit, tree digest, and subject hash.

Completion requires clean-checkout contract, Control, Go, race, platform,
native, migration, backup/restore, and release evidence; independent semantic
review; successful hosted required checks; and authenticated operator acceptance
and `achieve`. Any source change after evidence collection creates a new Subject
and invalidates stale receipts.

This goal starts only after 0006a-0006h are complete and all credentials,
provider access, hosted runners, approved repository identity, and operator
authority are available; the 12-hour bound starts after those prerequisites are
ready. It is one final independently mergeable PR and contains no unrelated or
historical evidence.
